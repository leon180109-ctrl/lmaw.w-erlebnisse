1.5 Datenbanken & ER-Modell

  • Entitäten (Tabellen): Reale Dinge/Konzepte (z.B. Mitarbeiter, Kunde).
  • Attribute (Spalten): Eigenschaften einer Entität (z.B. Name, Datum).
  • Primärschlüssel (PK): Eindeutige Identifikation jedes Datensatzes.
  • Fremdschlüssel (FK): Verweis auf PK einer anderen Tabelle.
  • Kardinalitäten: 1:1, 1:n, m:n
  • Kardinalitätsrestriktion [1,1]: Jede Abteilung wird von genau einem Angestellten geleitet.
  • Kardinalitätsrestriktion [0,1]: Ein Angestellter leitet entweder keine oder eine Abteilung.

1.6 Normalformen

  • 1. Normalform (1. NF): Alle Attributwerte sind atomar (nicht weiter zerlegbar).
  • 2. Normalform (2. NF): Jedes Nicht-Schlüssel-Attribut ist voll funktional abhängig vom gesamten Primärschlüssel.
  • 3. Normalform (3. NF): Keine transitiven Abhängigkeiten (Nicht-Schlüssel-Attribute hängen nur vom PK ab).

2.2 Grundlagenbegriffe

  • Anode & Kathode: Anschlüsse polarisierter Bauteile. Anode = positiv (+), Kathode = negativ (-).
  • SMD: Surface Mount Device – direkt auf Platine gelötet.
  • THT: Through-Hole Technology – bedrahtet, durch Platine gesteckt.
  • Farbcode: Farbringe auf Widerstand geben Wert (Ohm), Multiplikator und Toleranz an.

2.3 Ohmsches Gesetz & Grundformeln

U = R · I (Spannung = Widerstand × Stromstärke)

I = U / R (Stromstärke = Spannung / Widerstand)

R = U / I (Widerstand = Spannung / Stromstärke)

Einheiten: U in Volt (V), I in Ampere (A), R in Ohm (Ω)

Aufgabe 1 – Spannung berechnen

Durch einen Widerstand von 220 Ω fließt ein Strom von 0,02 A. Berechne U.

Lösung: U = R · I = 220 Ω · 0,02 A = 4,4 V

Aufgabe 2 – Stromstärke berechnen

An einem Widerstand von 1 kΩ liegen 5 V an. Berechne I in A und mA.

Lösung: I = U / R = 5 V / 1000 Ω = 0,005 A = 5 mA

Aufgabe 3 – Widerstand berechnen

Bei einer Spannung von 12 V fließt ein Strom von 0,06 A. Wie groß ist R?

Lösung: R = U / I = 12 V / 0,06 A = 200 Ω

Aufgabe 4 – Einheiten beachten

An einem Widerstand von 470 Ω fließt ein Strom von 15 mA. Berechne U.

Lösung: U = R · I = 470 Ω · 0,015 A = 7,05 V

Aufgabe 5 – Proportionaler Zusammenhang

Ein Verbraucher hat konstanten Widerstand. Die Spannung wird von 4 V auf 8 V verdoppelt. Was passiert mit der Stromstärke?

Lösung: Die Stromstärke verdoppelt sich. Nach dem Ohmschen Gesetz (I = U/R) ist die Stromstärke direkt proportional zur Spannung bei konstantem Widerstand.

Aufgabe 6 – Antiproportionaler Zusammenhang

An einer Spannungsquelle liegen konstant 12 V. Ein Widerstand wird von 200 Ω auf 400 Ω vergrößert. Was passiert mit der Stromstärke?

Lösung: Die Stromstärke halbiert sich. Nach dem Ohmschen Gesetz (I = U/R) ist die Stromstärke umgekehrt proportional zum Widerstand bei konstanter Spannung.

2.4 Zentrale Grundgesetze

  • Ohmsches Gesetz: U = R · I
  • Elektrische Leistung: P = U · I = I² · R = U² / R
  • Kirchhoffsches Knotenpunktgesetz (1. Gesetz): Die Summe aller zufließenden Ströme = Summe aller abfließenden Ströme (Σ Izu = Σ Iab).
  • Kirchhoffsches Maschengesetz (2. Gesetz): Die Summe aller Teilspannungen in einer geschlossenen Masche ist Null (Σ U = 0).

Reihenschaltung

  • Stromstärke: Iges = I1 = I2
  • Gesamtwiderstand: Rges = R1 + R2

Parallelschaltung

  • Spannung: Uges = U1 = U2
  • Gesamtwiderstand: 1/Rges = 1/R1 + 1/R2

}

3.4 Jump Game / Dino-Spiel (Projekt)

Ein LCD-Spiel mit einem Spieler (P), der Hindernissen ausweicht. Der Taster an Pin 10 lässt den Spieler springen.

Benötigte Bauteile

  • Arduino Nano (oder Uno)
  • 128x64 Graphical LCD (ST7920) oder 16x2 LCD mit I2C
  • 10 kΩ Potentiometer (Kontrast)
  • Taster an Pin 10
  • Jumper-Kabel, Breadboard

Vollständiger Code (Dino Jump Game)

#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);

int tasterPin = 10;
int spielerY = 1;
int hindernis1X = 15;
int hindernis2X = 14;

long alteZeit = 0;
int geschwindigkeit = 400;

void setup() {
  pinMode(tasterPin, INPUT);
  lcd.init();
  lcd.backlight();
}

void loop() {
  int knopf = digitalRead(tasterPin);
  if (knopf == HIGH) {
    spielerY = 0;   // Spieler springt hoch
  } else {
    spielerY = 1;   // Spieler bleibt unten
  }

  long aktuelleZeit = millis();
  if (aktuelleZeit - alteZeit > geschwindigkeit) {
    alteZeit = aktuelleZeit;
    lcd.clear();

    // Spieler zeichnen
    lcd.setCursor(1, spielerY);
    lcd.print("P");

    // Hindernisse zeichnen
    lcd.setCursor(hindernis1X, 1);
    lcd.print("*");
    lcd.setCursor(hindernis2X, 0);
    lcd.print("*");

    // Hindernisse bewegen
    hindernis1X = hindernis1X - 1;
    hindernis2X = hindernis2X - 4;

    if (hindernis1X < 0) hindernis1X = 15;
    if (hindernis2X < 0) hindernis2X = 15;

    // Kollisionsprüfung
    if (hindernis1X == 1 && spielerY == 1) {
      lcd.clear();
      lcd.setCursor(3, 0);
      lcd.print("GAME OVER");
      while (true);
    }
    if (hindernis2X == 1 && spielerY == 0) {
      lcd.clear();
      lcd.setCursor(3, 0);
      lcd.print("GAME OVER");
      while (true);
    }
  }
}

#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);

int tasterPin = 10;
int spielerZeile = 1;
int hindernis1_X = 0;
int hindernis2_X = 0;
int hindernis3_X = 0;
int abstand = 0;
int punkte = 0;

unsigned long zeitSpiel = 0;
unsigned long zeitLcd = 0;

void setup() {
  pinMode(tasterPin, INPUT);
  lcd.init();
  lcd.backlight();
  randomSeed(analogRead(0));
}

void loop() {
  if (digitalRead(tasterPin) == HIGH) {
    spielerZeile = 0;
  } else {
    spielerZeile = 1;
  }

  unsigned long jetzt = millis();

  // Spielschritt alle 300 ms
  if (jetzt - zeitSpiel >= 300) {
    zeitSpiel = jetzt;
    if (hindernis1_X > 0) hindernis1_X--;
    if (hindernis2_X > 0) hindernis2_X--;
    if (hindernis3_X > 0) hindernis3_X--;
    if (abstand > 0) abstand--;

    if (abstand == 0) {
      int zufall = random(0, 10);
      if (zufall == 1 && hindernis1_X == 0) { hindernis1_X = 15; abstand = 5; }
      if (zufall == 2 && hindernis2_X == 0) { hindernis2_X = 15; abstand = 5; }
      if (zufall == 3 && hindernis3_X == 0) { hindernis3_X = 15; abstand = 5; }
    }

    // Kollisionsprüfung
    if (hindernis1_X == 1 && spielerZeile == 1) {
      lcd.clear();
      lcd.setCursor(3, 0);
      lcd.print("GAME OVER");
      delay(500);
      while (digitalRead(tasterPin) == LOW) { }
      // Reset
      hindernis1_X = 0; hindernis2_X = 0; hindernis3_X = 0;
      punkte = 0;
    }
  }

  // LCD-Update alle 50 ms
  if (jetzt - zeitLcd >= 50) {
    zeitLcd = jetzt;
    lcd.clear();
    lcd.setCursor(1, spielerZeile);
    lcd.print("P");
    if (hindernis1_X > 0) { lcd.setCursor(hindernis1_X, 1); lcd.print("$"); }
    if (hindernis2_X > 0) { lcd.setCursor(hindernis2_X, 0); lcd.print("#"); }
    if (hindernis3_X > 0) { lcd.setCursor(hindernis3_X, 0); lcd.print("%"); }
    lcd.setCursor(12, 0);
    lcd.print(punkte);
  }
}

4.3 Kommunikationsmodelle

1. Vier-Ohren-Modell (Schulz von Thun)

Prinzipielle Funktion: Jede Nachricht besitzt zeitgleich vier Dimensionen: den Sachinhalt (Daten/Fakten), die Selbstkundgabe (was der Sender über sich offenbart), den Beziehungshinweis (was er vom Empfänger hält) und den Appell (was er erreichen möchte). Der Sender spricht mit „vier Schnäbeln", der Empfänger hört mit „vier Ohren".

2. Sender-Empfänger-Modell (Shannon & Weaver)

Prinzipielle Funktion: Beschreibt Kommunikation als standardisierten, linearen und rein technischen Prozess. Ein Sender kodiert Gedanken in ein Signal, das über einen Übertragungskanal an einen Empfänger gesendet wird, welcher die Signale dekodiert. Störquellen im Kanal können die Botschaft verzerren.

Entwicklungsgrund (1948): Claude Shannon und Warren Weaver entwickelten das Konzept für die Bell Telephone Laboratories. Ziel war die mathematische und technische Effizienz von Telefonleitungen und Funksystemen zu optimieren – maximale Daten mit minimalem Signalverlust durch fehleranfällige Medien.

3. 5 Axiome (Paul Watzlawick)

Prinzipielle Funktion: Fünf unumstößliche Grundregeln (Axiome), die das menschliche Verhalten im Austausch bestimmen. Es erklärt, wie Kommunikation unbewusst durch bloßes Vorhandensein einer Person abläuft, dass sie immer einen Beziehungsaspekt enthält und sich in kreisförmigen Reiz-Reaktions-Mustern bewegt.

Entwicklungsgrund (1969): Paul Watzlawick entwickelte die Axiome am Mental Research Institute (USA). Seine Motivation: Erforschung psychischer Verhaltensstörungen und familiärer Konflikte. Er wollte beweisen, dass gestörte Kommunikation nicht das Problem einzelner Personen ist, sondern aus einem fehlerhaften System resultiert.

4. Eisbergmodell (nach Sigmund Freud)

Prinzipielle Funktion: Teilt Kommunikation in sichtbaren und unsichtbaren Teil. Die sichtbare Sachebene (ca. 20 %) transportiert rationale Daten, Zahlen und verbale Fakten. Die unsichtbare Beziehungsebene (ca. 80 %) umfasst Gefühle, Instinkte, Ängste, Werte und Vorurteile, welche die Sachebene massiv steuern.

Entwicklungsgrund: Basiert auf Freuds Schichtenmodell der Psyche (Bewusstsein/Unterbewusstsein), wurde von Kommunikationswissenschaftlern wie Watzlawick für die Gesprächsführung adaptiert. Konflikte auf der Sachebene sind oft unlösbar, weil die eigentliche Ursache tief in emotionalen Spannungen liegt.

5. Transaktionsanalyse (Eric Berne)

Prinzipielle Funktion: Analysiert Kommunikationseinheiten (Transaktionen) basierend auf psychologischen Rollenmustern. Es untersucht, aus welchem inneren Zustand heraus eine Person spricht: Eltern-Ich (belehrend/fürsorglich), Erwachsenen-Ich (sachlich/konstruktiv) oder Kind-Ich (emotional/trotzig).

Entwicklungsgrund (1950er): Eric Berne entwickelte die Transaktionsanalyse als verständliche Alternative zur klassischen Psychoanalyse. Ziel: Ein nahbares, leicht vermittelbares psychotherapeutisches Konzept, mit dem Patienten eigene Verhaltensmuster schnell durchschauen und gezielt ins sachliche „Erwachsenen-Ich" steuern können.

6. Organon-Modell (Karl Bühler)

Prinzipielle Funktion: Definiert das sprachliche Zeichen (gesprochenes Wort) als Werkzeug. Ordnet der Sprache drei Kernfunktionen in Abhängigkeit von Sender, Empfänger und Gegenstand zu: Ausdrucksfunktion (Sender teilt Gefühle mit), Appellfunktion (Empfänger wird gelenkt) und Darstellungsfunktion (Sachverhalte der Welt werden beschrieben).

Entwicklungsgrund (1934): Karl Bühler veröffentlichte das Modell in „Sprachtheorie". Er wollte die Linguistik aus ihrer rein grammatikalischen Verengung befreien und ein Modell schaffen, das Sprache als dynamisches, soziales Handlungswerkzeug erfasst.

7. NLP-Modell (Neurolinguistisches Programmieren)

Prinzipielle Funktion: Beschreibt, wie neurologische Prozesse („Neuro") durch Sprache („Linguistisch") organisiert und im Verhalten verankert („Programmieren") werden. Menschen erzeugen über Filter subjektiv verzerrte „innere Landkarten".

Entwicklungsgrund (1970er): Richard Bandler und John Grinder entwickelten NLP an der University of California. Ziel: Verhaltens- und Sprachmuster erfolgreicher Therapeuten (Virginia Satir, Milton Erickson) entschlüsseln und kopierbar machen („Modeling").

6.1 Mechanik & Energie

Mechanische Arbeit

Definition: Arbeit ist das Produkt aus der wirkenden Kraft F und dem zurückgelegten Weg s in Kraftrichtung.

Formel: W = F · s

Einheit: Newtonmeter (Nm) oder Joule (J), 1 J = 1 Nm = 1 Ws

Arbeitskomponente und arbeitslose Komponente

  • Arbeitskomponente Fx: Fx = F · cos α (parallel zur Wegrichtung)
  • Arbeitslose Komponente Fy: Fy = F · sin α (senkrecht zur Wegrichtung, verrichtet keine Arbeit)
  • Mechanische Arbeit (schräg): W = F · cos α · s

Hubarbeit und potentielle Energie

Hubarbeit: Wh = FG · h = m · g · h

Potentielle Energie: Wpot = m · g · h

Kinetische Energie

Bewegungsenergie: Ekin = ½ · m · v²

Energieerhaltungssatz

In einem energetisch abgeschlossenen System ist die Gesamtenergie konstant. Energie kann weder erzeugt noch vernichtet, sondern lediglich von einer Energieform in eine andere umgewandelt werden.

Goldene Regel der Mechanik

„Was an Kraft gespart wird, muss an Weg zugesetzt werden." In einem idealen System: F1 · s1 = F2 · s2

6.2 Aufgaben mit Lösungen

M1: Kurbel (Drehmoment und Arbeit)

Ein Mann dreht eine Kurbel mit Radius r = 0,5 m bei Handkraft FH = 250 N insgesamt 80-mal herum.

a) Drehmoment: M = FH · r = 250 N · 0,5 m = 125 Nm

b) Arbeit:

  • Weg für 1 Umdrehung: s1 = 2 · π · r = 2 · π · 0,5 = π ≈ 3,1416 m
  • Gesamtweg: sges = 80 · 3,1416 ≈ 251,33 m
  • Arbeit: W = FH · sges = 250 · 251,33 ≈ 62.831,85 J ≈ 62,83 kJ

Typischer Fehler: Nur den Radius oder nur 1 Umdrehung rechnen, ohne die 80 Umdrehungen zu berücksichtigen.

M2: Arbeiter im Treppenhaus

Ein Arbeiter (75 kg) geht vom 1. Stock in den 3. Stock, trägt 250 N Last. Geschosshöhe = 3,2 m.

Fehler 1: Falsche Etagenanzahl (vom 1. in den 3. Stock sind es 2 Geschosse, nicht 3). Höhe = 2 · 3,2 = 6,4 m.

Fehler 2: Vergessen des eigenen Körpergewichts. FGKörper = 75 · 9,81 = 735,75 N. Fges = 735,75 + 250 = 985,75 N.

Lösung: W = Fges · h = 985,75 N · 6,4 m = 6.308,8 J ≈ 6,31 kJ

Ü7: Endgeschwindigkeit mit Antriebskraft

F = 100 N, sges = 93 m, Δh = 4 m, m = 5 kg.

  1. Zugeführte Arbeit: Wzufuhr = 100 · 93 = 9.300 J
  2. Nötige Hubarbeit: Epot,nötig = 5 · 9,81 · 4 = 196,2 J
  3. Verbleibende Ekin: 9.300 - 196,2 = 9.103,8 J
  4. Endgeschwindigkeit: v = √(2 · 9.103,8 / 5) ≈ 60,34 m/s ≈ 217,2 km/h

Ü8: Energie eines Stausees

V = 80.000 m³ (m = 80.000.000 kg), h = 360 m, g = 9,81 m/s²

  • Kilowattstunde: 282.528.000.000 / 3.600.000 = 78.480 kWh

Musterlösung: Energie bei Kuppe und Rampe

m = 5 kg, v0 = 9 m/s, h1 = 2 m (Kuppe), α = 30° (Rampe), g = 9,81 m/s².

a) Geschwindigkeit auf der Kuppe:

Ekin,0 = Ekin,1 + Epot,1

½ · m · v0² = ½ · m · v1² + m · g · h1

½ · v1² = ½ · v0² - g · h1

v1 = √(v0² - 2 · g · h1) = √(81 - 39,24) ≈ 6,46 m/s

b) Maximale Höhe auf der Rampe:

Ekin,0 = Epot,2

½ · v0² = g · h2

h2 = v0² / (2 · g) = 81 / 19,62 ≈ 4,13 m

c) Rolle der Kuppe: Die Höhe der Kuppe hat keinen Einfluss auf das Endergebnis (sofern h1 ≤ h2). Beim Überfahren wird vorübergehend kinetische in potentielle Energie umgewandelt, beim Hinabfahren vollständig zurückverwandelt. Die erreichbare Höhe h2 hängt ausschließlich von der Anfangsenergie ab.

8.1 Das Erdbeben in Chili

Inhaltsangabe

In der Novelle „Das Erdbeben in Chili" von Heinrich von Kleist geht es um zwei junge Menschen in St. Jago im Jahr 1647, die wegen ihrer verbotenen Liebe bestraft werden sollen. Der junge Lehrer Jeronimo Rugera und die edle Donna Josephe (Tochter von Don Henrico Asteron) haben ein heimliches Kind namens Philipp bekommen. Jeronimo wird ins Gefängnis gesperrt, Josephe soll enthauptet werden – Erzbischof, Äbtissin und Vizekönig verurteilen die Tat streng.

Genau im Moment der Hinrichtung bricht ein riesiges Erdbeben aus und zerstört fast die ganze Stadt. Jeronimo entkommt durch einstürzende Mauern, Josephe rettet ihr Baby aus dem brennenden Kloster. Beide fliehen unabhängig und treffen sich glücklich im grünen Tal wieder.

Im Tal treffen sie auf Don Fernando und Donna Elvire, die helfen wollen. Alle Menschen wirken nach der Katastrophe friedlich, sie beschließen in die Kathedrale zu gehen. Doch ein Dominikaner hält eine Hetzpredigt und gibt den Liebenden die Schuld am Gottesurteil. Meister Pedrillo (früher für Henrico tätig) erkennt das Paar und ruft zum Mord auf.

Es kommt zum Tumult, Jeronimo und Josephe werden erschlagen. Don Fernando verteidigt die Kinder, aber Pedrillo packt seinen Sohn Juan und zerschmettert ihn an einem Kirchpfeiler. Am Ende überlebt Philipp, Don Fernando und Donna Elvire nehmen ihn als Pflegesohn auf.

Varianten Einleitung

Variante 1: Heinrich von Kleists Novelle „Das Erdbeben in Chili" erzählt von einem jungen Paar, das wegen einer verbotenen Liebe von Kirche und Gesellschaft zum Tode verurteilt wird. Genau im Moment der Hinrichtung zerstört ein Erdbeben die Stadt. Was zuerst wie eine göttliche Rettung wirkt, entlarvt am Ende die wahre Grausamkeit der Menschen und die Heuchelei einer Ordnung, die sich auf Moral und Glauben beruft.

8.2 Die Marquise von O...

Thema

Unverschuldete Not und gesellschaftliche Isolation durch eine Tat eines Menschen, der Retter gilt aber die Situation missbrauchte.

Ablauf

  1. Graf F... rettet die Marquise vor Soldaten; er vergeht sich unbemerkt an der Bewusstlosen.
  2. Die Marquise bemerkt ihre Schwangerschaft, hat aber keine Erinnerung an ein Vergehen.
  3. Die Familie glaubt ihr nicht; der Vater schmeißt sie wütend aus dem Haus.
  4. Die Marquise sucht per Zeitungsanzeige öffentlich nach dem Vater ihres Kindes.

Keine reinen Schwarz-Weiß-Kategorien: Menschen sind vielschichtig – der edle Retter kann gleichzeitig der Täter sein („Teufel und Engel").

8.3 Der zerbrochene Krug

Inhaltsangabe

Ausgangssituation: Handlung spielt in Huisum (Niederlande). Dorfrichter Adam wacht morgens auf mit Kopfschmerzen, verletztem Bein und ohne Perücke. Adam war nachts heimlich bei Eve, der Verlobten von Ruprecht.

Der Konflikt: Gerichtsrat Walter kommt überraschend zur strengen Kontrolle ins Dorf. Bäuerin Marthe kommt wütend mit Scherben ihres wertvollen Kruges und wirft Ruprecht vor, den Krug nachts zerstört zu haben.

Die Verhandlung: Ruprecht streitet alles ab und nennt einen unbekannten Fliehenden. Eve schweigt erst aus Schutz, will dann aber die Wahrheit sagen. Frau Brigitte bringt Adams verlorene Perücke und Fußspuren vom Pferdefuß als Beweis.

Das Ende: Adam gerät in die Enge, fällt ein falsches Urteil und flieht. Walter deckt Adams Erpressung mit einem falschen ärztlichen Attest auf. Ruprecht und Eve werden freigesprochen, das Paar bleibt zusammen.

Spannungskurve

  • Exposition: Adam ist verletzt und Walter kündigt strenge Kontrolle an.
  • Steigende Handlung: Marthe bringt den zerbrochenen Krug, Zeugen werden befragt, Adam lenkt panisch ab.
  • Höhepunkt: Brigitte bringt Perücke und Fußspuren als Beweis, Adam wird überführt und flieht.
  • Fallende Handlung: Walter klärt die Erpressung auf und rehabilitiert Ruprecht und Eve.

Wichtige Worterklärungen

  • Gevatter: Guter Freund oder Nachbar
  • Ältervater: Urgroßvater (hier gemeint als Adam)
  • Klumpfuß: Kranker oder unförmiger Fuß
  • Schubiack: Schlechter, unzuverlässiger Mensch
  • Konskription: Offizielle Liste für den Zwangsdienst beim Militär

Adams Erpressung (Auflösung)

Adam wollte Ruprecht mit einem falschen Attest vor dem Krieg in Asien retten. Als Gegenleistung sollte Eve ihm gehorchen.

Der nächtliche Vorfall: Adam schloss Eves Tür ab, legte seine Perücke auf den Krug. Als Ruprecht anklopfte, sprang Adam aus dem Fenster und warf den Krug um.

Happy End: Walter erklärt, dass die Soldaten in Holland bleiben und Adams Erpressung eine Lüge war. Eve bekommt Geld als Entschädigung, die Hochzeit findet statt.

11. Wirtschaft & Recht

11.1 Streik – Definition

Ein Streik ist eine planmäßig durchgeführte Arbeitsniederlegung von gemeinsam handelnden Arbeitnehmern mit Durchführungszielen, die von der Gewerkschaft organisiert wird und mit der Durchsetzung der Vereinbarung endet.

11.2 Ziele von Streiks

  • Druck machen: Die Arbeitgeber sollen merken, dass ohne die Beschäftigten nichts läuft.
  • Mehr Kohle: Höhere Löhne und Boni als Ausgleich für steigende Preise (Inflation).
  • Bessere Arbeitszeiten: Weniger Wochenstunden, mehr Urlaub, besserer Arbeitsschutz.
  • Faire Verhandlungen: Ausgleich, damit die Chefs nicht alles alleine bestimmen.

11.3 Wird in Deutschland zu viel gestreikt?

Ja: Streiks bei Bahn, Flughäfen oder ÖPNV nerven im Alltag extrem und schaden der Wirtschaft.

Nein: Streiken ist ein Grundrecht im Grundgesetz. Im Vergleich zu Frankreich oder Dänemark gibt es in Deutschland voll wenige Streiktage.

Fazit: Streiks sind in Deutschland gesetzlich streng geregelt und werden meist erst nach erfolglosen Tarifverhandlungen als letztes Mittel eingesetzt. Deutschland liegt bei jährlichen Ausfalltagen im internationalen Vergleich lediglich im Mittelfeld.

11.4 Rechtmäßigkeit eines Streiks

Der Streik steht unter dem Gebot der Verhältnismäßigkeit:

  • Nur als letztes Mittel nach Ausschöpfung aller Verständigungsmöglichkeiten.
  • Darf nicht auf Vernichtung des Tarifgegners abzielen.
  • Muss möglichst rasch beendet werden, sobald Zweck erreicht.
  • Träger können nur Gewerkschaften sein (kein Betriebsrat).
  • Muss tariflich regelbare Ziele haben (keine politischen Streiks).
  • Darf nicht gegen geltenden Tarifvertrag verstoßen (Friedenspflicht).

  • Ostdeutschland: Sinkt von rund 55 % (2000) auf rund 45 % (2025).
  • Das Westniveau lag stets über dem ostdeutschen Niveau, die Kurven haben sich angenähert.

Ursachen für Rückgang der Tarifbindung

  1. Wandel des Wirtschaftssystems (Branchenstruktur): Branchen gewachsen, in denen Tarifverträge untypisch sind (Start-ups, privater Dienstleistungssektor).
  2. Organisationsschwierigkeiten bei kleineren Betrieben: Kleinere Betriebe sind für Gewerkschaften schwer zu organisieren.
  3. Aufweichen des Automatismus „Industrie gleich Tarif": Gilt nicht mehr uneingeschränkt (Beispiel: Tesla in Grünheide).

Mein Urteil: Insgesamt halte ich das Baukastenprinzip für einen diskussionswürdigen, aber kritischen Kompromiss. Aus Sicht der Gründerin spricht dafür, dass Flexibilität für kleine Start-ups dringend benötigt wird. Dagegen lässt sich einwenden, dass die Gewerkschaft befürchtet, dass das Tarifsystem dadurch ausgehöhlt werden könnte und Arbeitnehmerrechte an Gewicht verlieren. Ich spreche mich gegen ein unkontrolliertes Baukastenprinzip aus, da verlässliche Mindeststandards für Arbeitnehmer geschützt bleiben müssen, befürworte jedoch vereinfachte und passgenaue Regelwerke für Kleinbetriebe.
